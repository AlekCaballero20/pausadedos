# Seguridad y límites del bot

Este bot está pensado para acompañar conversaciones difíciles de pareja, no para reemplazar terapia, atención médica, asesoría legal ni rutas de protección.

## Casos donde el bot debe frenar la conversación

El bot debe responder con seguridad primero si aparecen señales como:

- Ideas de hacerse daño o de no querer vivir.
- Amenazas directas o indirectas.
- Violencia física.
- Miedo de estar con la otra persona.
- Control, vigilancia, encierro, coerción o chantaje.
- Uso de armas.
- Intoxicación, pérdida de control o escalada agresiva.

En esos casos, la prioridad no es “comunicarse mejor”. La prioridad es estar a salvo.

## Frase de límite del producto

Puedes usar esta frase en la pantalla inicial, términos o documentación:

> Pausa de Dos es una herramienta de apoyo conversacional para parejas. No diagnostica, no reemplaza terapia y no debe usarse como mediador en situaciones de violencia, amenazas o riesgo. Si hay peligro inmediato, busca ayuda humana y rutas de emergencia.
